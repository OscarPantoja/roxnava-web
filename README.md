# Rox Nava Web

Sitio web oficial de Rox Nava.

Este proyecto tiene como objetivo ofrecer una experiencia web moderna, rápida y accesible, centralizando la información pública, enlaces oficiales y novedades de la marca en un solo lugar.

---

## Objetivos

- Desarrollar una experiencia enfocada en dispositivos móviles (Mobile First).
- Mantener un diseño moderno, elegante y minimalista.
- Optimizar el rendimiento y la velocidad de carga.
- Aplicar buenas prácticas de accesibilidad (WCAG).
- Implementar una arquitectura escalable y fácil de mantener.
- Centralizar enlaces oficiales e información relevante.

---

## Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
